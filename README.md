# Mini Kinyarwanda Voice Assistant 🤖🇷🇼

This project simulates a simple voice assistant in Kinyarwanda.

## How it works:
- 🎙️ Record an audio file asking a question.
- 📜 The assistant transcribes it.
- 🧠 It matches your question to a known answer.
- 🗣️ It speaks back the answer using TTS.

## Requirements
- Python 3
- whisper
- gTTS
- playsound
- sounddevice
- scipy

## How to Run
1. Record audio using `record_audio.py`.
2. Run `main.py`.
3. Speak to the assistant!
